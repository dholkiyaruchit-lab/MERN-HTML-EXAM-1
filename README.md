# 🚀 CrytoM5 – Table Based Crypto Website

CrytoM5 is a **fully structured cryptocurrency landing page** built using  
**HTML + CSS (Table Layout Based Design)**.

It includes sections such as **Hero Banner, Features, Traders, Pricing Plans, Articles, Clients & Contact Form** — all created using HTML table formatting.

---

## 📌 Features of the Project

✔ Table-Based Layout (No Flex/Grid Used)  
✔ Hero Section with Image  
✔ Features Grid (Icons + Text)  
✔ Our Traders Section (Profile Cards)  
✔ Skills Section (Range Sliders)  
✔ Pricing Table (3 Plans)  
✔ Article Section (Images + Links)  
✔ YouTube Video Embed  
✔ Client Logos Section  
✔ Contact Form

## 🚀 How to Run the Project

1. Download the project folder  
2. Make sure your `Assets/` folder contains all required images  
3. Open **index.html** in any browser  
4. Done ✔ Your website will open!
